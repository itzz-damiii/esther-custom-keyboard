## Journal — Day 1
**Time spent: 1hr 12m **

### What I did
- Read through the initial sections of the keyboard docs
- Decided on 65% keyboard layout
- Sketched out the initial design
- Researched the parts I'd need
- Decided to include add ons like LEDs, a rotary encoder, and an oled screen (possibly)

### Design decisions
I initially considered a cloud-shaped keyboard, but changed my idea to a more standard keyboard shape with a hibiscus-inspired center

### What I learned
- The Raspberry Pi Pico will act as the microcontroller for the entire keyboard
- The keyboard uses a switch matrix so the Pico can detect many keys using fewer GPIO pins.
- I learned what GPIO pins and PCB silkscreen are.
